# Checked v4 Codec Survey Bindings

`generated.rs` and `codec_cases.u.pb.rs` are test-only output from
`proto/codec_cases.proto` using the repository's pinned upstream protobuf
`v35.1` source (`vendor/google/SHA`:
`35cd01f9fe9afbeea38cc7b979a3b6bfcde82c03`) with built-in Rust output
and `--rust_opt=experimental-codegen=enabled,kernel=upb`. The generated
version assertion is `4.35.1-release`, matching this benchmark's pinned
`protobuf` dependency. The locally built `protoc` SHA-256 was
`e2b116ef44d4b7f3246945ceb1938c72f04e16040020e321ac601869135ab940`.
`manifest.json` records the source and generated SHA-256 digests.

The default local build requires genuine pinned `libprotoc 35.1` with
`--rust_out`; it rejects a mismatched compiler or changed generated bytes.
A CI environment without that Rust generator opts into
`PURE_PROTOBUF_CHECKED_V4=1`: `build.rs` refuses a changed source schema and
copies the checked output to `OUT_DIR`, while the preceding Python integrity
test verifies the source and generated SHA-256 digests. This benchmark step
does not download a Rust generator; the existing CI `protoc` handles pbrs and
prost generation from the proto3 source.
These correctness tests are not a release-mode performance qualification.

Regenerate only with the reviewed matching compiler and update the manifest
after inspecting the generated diff:

```sh
./scripts/build-pinned-protoc.sh
target/pinned-protoc-build/protoc -I proto \
  --rust_out=tonic-bench/checked_v4 \
  --rust_opt=experimental-codegen=enabled,kernel=upb \
  proto/codec_cases.proto
```

After updating `manifest.json`, verify checked integrity and both build paths:

```sh
python3 -B -m unittest discover -s tonic-bench -p 'test_checked_v4.py' -q
PROTOC="$(pwd)/target/pinned-protoc-build/protoc" \
  CARGO_BUILD_JOBS=2 CARGO_TARGET_DIR=target \
  cargo test --locked --manifest-path tonic-bench/Cargo.toml --bin tonic-bench
PROTOC="$(pwd)/target/pinned-protoc-build/protoc" \
  PURE_PROTOBUF_CHECKED_V4=1 CARGO_BUILD_JOBS=2 CARGO_TARGET_DIR=target \
  cargo test --locked --manifest-path tonic-bench/Cargo.toml --bin tonic-bench
```
