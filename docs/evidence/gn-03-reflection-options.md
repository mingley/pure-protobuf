# GN-03: reflection and format emission options

This is dev-loop, contended-host evidence for the GN-03 option slice.

## Hypothesis

Generated consumers that do not need reflection, ProtoJSON, or text format
should be able to opt out so generated code does not reference
`DescriptorPool`, embedded `FILE_DESCRIPTOR_SET`, `pbrs::json`, or
`pbrs::text`. Defaults must remain source-compatible and byte-identical.

## Changes

- Added positive `Config::emit_reflection(bool)` and plugin
  `emit_reflection=true|false`.
- Added independent `Config::emit_json(bool)` / `Config::emit_text(bool)` and
  plugin `emit_json=true|false`, `emit_text=true|false`.
- Kept existing `no_reflect=true` as a shorthand for reflection-free generation
  that also defaults JSON/text methods off.
- Split JSON/text method emission so disabling either format removes references
  to its runtime module. Descriptor-backed dynamic JSON/text methods are skipped
  when reflection is disabled.
- Exposed `pbrs::RECURSION_LIMIT` in no-reflect runtime builds so binary parser
  generated code compiles with `pbrs = { default-features = false }`.
- Added SB-09 harness knobs:
  `SB09_PBRS_EMIT_REFLECTION`, `SB09_PBRS_EMIT_JSON`,
  `SB09_PBRS_EMIT_TEXT`, and `SB09_PBRS_RUNTIME_PROFILE`.

Accessor-only smoke run:

```sh
SB09_PBRS_EMIT_REFLECTION=0 SB09_PBRS_EMIT_JSON=0 SB09_PBRS_EMIT_TEXT=0 \
  CARGO_BUILD_JOBS=3 ./scripts/codegen-bench.sh --case small \
  --generators pbrs --repeats 1 --jobs 3 --generation-only \
  --out target/codegen-bench/gn0203-smoke-lean-20260929T014810Z
```

`grep -R "pbrs::json\\|pbrs::text\\|DescriptorPool\\|FILE_DESCRIPTOR_SET"` on
that generated tree returned no matches. The generated consumer built with:

```sh
pbrs = { path = ".../fleet-gn-02-03-shrink", default-features = false }
```

after generating an offline lockfile.

## Limits

- The descriptor bytes are optional in the accessor-only profile. Default
  multi-file output still embeds descriptor bytes per standalone generated file
  so existing `include!(OUT_DIR/service.rs)` users remain source-compatible.
  Sharing descriptor bytes for `mod.rs`-only consumers while preserving
  standalone `*.rs` includes needs a follow-up design.
- If reflection is off, messages that require descriptor-backed dynamic
  JSON/text (for example some WKT mappings) do not emit those format methods.
  Defaults are unchanged.
