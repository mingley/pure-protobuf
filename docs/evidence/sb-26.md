# Adoption matrix evidence (SB-26)

Status on 2026-09-30: corpus qualification delivered by SB-26a; 512 codec
operations qualified under SB-26c. Matrix measurement remains open under
SB-26b and its SB-26c/d/e children. These are dev-loop prerequisites, not
performance leadership evidence.

`2ac07df288373f80f93cd8c6e25a27ea5ef8bb4d`, from source base
`34fffc29dbf872f642b38baafb8e2ed90f518832`.
The [consumer](../../bench/devloop/adoption/README.md) records commands and
build prerequisites. The [inventory](../../bench/devloop/adoption/evidence/inventory.json)
retains each fixture's bytes/checksum and equality result; the
[qualification](../../bench/devloop/adoption/evidence/qualification.json)
binds exact source blobs, tool/dependency pins and command results.

Every one of the 64 runtime specimens passes full equality through the
independent generated prost representation and matching complete read walks.
The walks read presence and every byte, including decoding the generated
Payload inside Any. The seven tests separately exercise every sparse field's
present default, typed oneof defaults/absence, exact depths and predicate
kinds, changed last-record bytes and reordered/changed maps. Two complete
inventory runs produced identical JSON. Strict standalone Clippy, format and
fixture regeneration checks pass. The existing codec-bench gate also built and
ran all 21 legacy specimens; its fixed-order timing is not the adoption baseline.

SB-26c's [codec inventory](../../bench/devloop/adoption/evidence/codec-inventory.json)
qualifies every specimen in fresh-encode, owned-decode, read-all and
fully-read-clone operations for both codecs. Native fresh constructors use
generated APIs directly, including encoding their own Any Payload. Before
measurement, preparation checks fresh, decoded and cloned full equality and
complete reads. The eighth corpus test executes all 512 operations and checks
their lengths/checksums; two inventory runs are byte-identical. The original
64-specimen inventory remains byte-identical after matching exact-size
payload construction across codecs. Maps retain pbrs's four extra bytes for
default-valued entries; both codecs decode to identical values.
The [codec qualification](../../bench/devloop/adoption/evidence/codec-qualification.json)
records exact source blobs, checks and the pending collector boundary.

The registered collector built with pinned Linux protoc 35.1 and exposes all
512 qualified IDs. Its first 64 native fresh-encode cells now have measured

[per-cell report](../../bench/devloop/adoption/evidence/codec-baseline/pbrs-fresh_encode.json).
The [measurement record](../../bench/devloop/adoption/evidence/codec-measurement.json)

and cross-codec comparisons are in progress. Instrumented wall time and this
single VM do not establish native latency or claim-grade performance.
