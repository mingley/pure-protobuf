# SV-07: accept scaling and per-connection memory premise check

## Scope

SV-07 proposed optional `SO_REUSEPORT` multi-acceptor listeners, accept
batching, and idle-connection memory reduction.

## Current source state

The major `SO_REUSEPORT` multi-acceptor piece already exists from RX-02:

- `pbrs-grpc/src/rt/per_core.rs::reuseport_listener` binds
  `SO_REUSEADDR` + `SO_REUSEPORT`.
- `pbrs-grpc/src/server/accept.rs` exposes:
  - `Server::serve_per_core`;
  - `Server::serve_tls_per_core`;
  - `Server::bind_per_core`;
  - `Server::serve_per_core_on`;
  - the same Router variants.
- `rpc-bench server --cores N` exercises native per-core server mode.
- `docs/evidence/rx02-per-core.md` records the delivered scaling evidence and
  tests.

That means this worker should not reimplement the multi-acceptor design in
`server/accept.rs` or `tcp.rs`.

## Accept batching assessment

`accept_loop_with_slots` currently awaits one `listener.accept()` per loop and
spawns one connection task per accepted socket. Batching accepts could reduce
accept-loop wakeups during connection storms, but it is not measurable with
the current SV-01 local cells:

- dev-loop RPC cells reuse existing loopback connections and do not stress
  accepts;
- the short `rpc-bench load` cells used stable client connection pools;
- SB-12 connection-scale / handshake-rate cells are the right evidence source
  but were not run in this workstream.

## Verdict

No code change. The `SO_REUSEPORT` part is already implemented and tested by
RX-02; accept batching is deferred until a connection-storm or handshake-rate
cell proves it is a limiting cost.

## Follow-up requirements

Before implementing accept batching:

1. Add or run SB-12-style cells for accept rate, TLS handshake rate, and
   connection storms.
2. Record p50/p99 accept-to-preface latency, rejected connection counts, and
   RSS deltas.
3. Prove connection caps and graceful drain behavior remain identical.
4. Reuse the existing per-core/sharded accept framework instead of adding a
   second listener architecture.
